Why Non-Linearity Matters

An interactive walkthrough of the XOR problem, showing why a neural network needs non-linear activation functions to classify data that isn't linearly separable.

The Problem: XOR

The XOR function outputs 1 when exactly one of its inputs is 1. These four points cannot be separated by a single straight line.

x₁x₂XOR (y)
000
011
101
110

Original XOR points in input space. No single line can separate the classes.

The Network

We use a simple 2-layer neural network: 2 inputs → 2 hidden units (with ReLU) → 1 output (with binarize). The parameters are:

W = [[-1, 1], [-1, 1]]   b⁽¹⁾ = [1.4, -0.6]   V = [-1, -1]   b⁽²⁾ = 1

Step 1: Compute the linear transform z = Wx + b⁽¹⁾
For each XOR point, compute z₁ = -x₁ - x₂ + 1.4 and z₂ = x₁ + x₂ - 0.6
Pointz₁z₂
(0, 0)
(0, 1)
(1, 0)
(1, 1)
After the linear transform, the points have moved but they are still not linearly separable. A linear model alone cannot solve XOR.
Step 2: Apply ReLU — h = max(0, z)
ReLU clips negative values to 0. Compute h₁ = max(0, z₁) and h₂ = max(0, z₂) for each point.
Pointh₁h₂
(0, 0)
(0, 1)
(1, 0)
(1, 1)
After ReLU, the points are now linearly separable! The non-linear activation folded the space so that a single line can separate the two classes. This is why non-linearity matters.
Step 3: Compute the output z' = Vh + b⁽²⁾ and binarize
Compute z' = -h₁ - h₂ + 1, then y = 1 if z' ≥ 0, else 0
Pointz'y
(0, 0)
(0, 1)
(1, 0)
(1, 1)
The network correctly classifies all four XOR points. Without ReLU, this would be impossible: stacking linear layers without activation functions is equivalent to a single linear model, regardless of depth.
