RNAseq
Explorer

An interactive tool for visualizing RNA-seq transcript profiles and differential gene expression from public GEO datasets or user-uploaded data.

RNA-seq Transcriptomics GEO Datasets Differential Expression Python Streamlit

How It Works

01

Load Data

Enter a GEO Series accession (e.g. GSE53757) to automatically fetch expression data and sample metadata, or upload your own count matrix and metadata files.

02

Explore with PCA

Run principal component analysis on the top variable genes. Color samples by any metadata variable to reveal batch effects, treatment groups, or tissue-specific clustering.

03

Differential Expression Analysis

Select control and treatment groups, then run DEG analysis. Uses DESeq2 for count data or t-test with BH correction for normalized data. View interactive volcano plots with labeled top hits.

04

Gene Search

Search for any gene by name and view its expression across all samples. Box plots grouped by condition reveal gene-level differences at a glance.
