Vina Plug
& Play

An interactive molecular docking tool powered by AutoDock Vina. Designed to make protein-ligand docking accessible to researchers without programming experience.

Molecular Docking AutoDock Vina Drug Discovery Python Streamlit

How It Works

01

Provide a Ligand

Enter a SMILES string and the tool generates a 3D conformer with RDKit, optimizes geometry with MMFF force field, and converts to PDBQT via Meeko. Or upload a pre-prepared .pdbqt file directly.

02

Prepare the Receptor

Enter a PDB ID to fetch the structure from RCSB, or upload your own .pdb file. The tool automatically detects and removes co-crystallized ligands and water molecules, with options to retain metal ions.

03

Define the Binding Pocket

Set the search space using a co-crystallized ligand as reference or specify coordinates manually. Configure the pocket radius and docking parameters (exhaustiveness, number of poses).

04

Run Docking & View Results

AutoDock Vina scores and ranks binding poses. View a table of binding energies (total, intermolecular, intramolecular) and download docked poses as PDB files for visualization in PyMOL or ChimeraX.
